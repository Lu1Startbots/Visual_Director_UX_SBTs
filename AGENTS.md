# Codex / Claude / Kiro - instrucciones del kit STARBOTS V-DLC

Esta carpeta es un **kit de definicion para construir un repositorio NUEVO**, no una aplicacion ya implementada. No confundir textos de ejemplo con API real.

1. Primera sesión: leer `00_EMPIEZA_AQUI.md` y `prompts/01_PRIMERA_SESION_CODEX.md`; solo diagnostico y plan.
2. Antes de código: contrato, checklist de acceptacion y aprovisionamiento aprobado.
3. Construir un vertical slice verificable antes de ampliar arquitectura.
4. Primera iteracion read-only: un scanner que detecta defectos reales en fixtures.
5. Git privado y ramas, nada de push/deploy/fusion automática.
6. No tocar la web real, otros proyectos o secretos sin autorización especifica.
7. No aceptar baselines/snapshots sin review humano.
8. Documentar licencias antes de copiar repo externo. No duplicar Impeccable/Playwright/axe.
9. El motor genérico y la identidad/copy/Orbit/bocetos privados de Starbots van separados.
10. Retornar siempre resultados verificables con comandos y pruebas ejecutadas o NOT_RUN.

No incluir `references-private/` ni assets privados al publicar en GitHub. No reutilizar archivos de otros repos sin permiso.
