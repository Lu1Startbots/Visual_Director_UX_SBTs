# Políticas base de revision visual

- Theme dark-first, light disponible con contraste y superficies deliberadas.
- Morado de marca como acento, no clases arbitrarias.
- Tipografía y spacing desde roles y tokens aprobados.
- Botones y cards desde componentes oficiales; excepciones de marca con nombre propio.
- Una familia de iconos primaria (Phosphor), SVGs propios para simbolos de Starbots.
- Glass/blur/motion y art ASCII son excepciones moderadas, con buen contraste y reduced motion.
- Focus visible, lectura sin clipping, componentes responden a widths 360/390/768/1024/1440/1920 segun proyecto.
- Meet Orbit: boceto IMG_3925; Ask/Contact: IMG_3927; Starbots Film: IMG_3926. Los bocetos son referencia estructural, no snapshots pixel perfect.
- Orbit es una imagen de marca protegida; no cambiar silueta, ojos o apariencia.
- El criterio humano prevalece cuando un cambio es artistico. No confundir opinion de IA con gate determinista.
- No subir assets privados, screenshots con PII ni secretos a providers sin consentimiento.
