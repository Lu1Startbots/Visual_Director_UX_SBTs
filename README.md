# Visual-Director-Ux-by-SBTs

STARBOTS V-DLC — Visual Design Lifecycle

**Kit de especificación para construir con Codex. No es un release funcional de software.**

Objetivo: un Visual Director reusable que gobierne design tokens, componentes, tipografía, jerarquía, layouts, tema dark/light, accesibilidad, capturas, regresiones y calidad visual; consumible por Codex, Claude y Kiro, con CI/GitHub y aprobaciones humanas.

- Lee `00_EMPIEZA_AQUI.md` para empezar.
- Primer prompt: `prompts/01_PRIMERA_SESION_CODEX.md`.
- Todos los requerimientos estan en `docs/`.
- Primer motor MVP: U1 CLI + regla real + fixtures + JSON/Markdown + tests.
- Material grafico/Blueprint corporativo: `references-private/` (fuera de Git).
- Skill starter: `agent-skills/starbots-visual-director/`, independiente del motor.

La especificación compara el enfoque con AI-DLC, pero no es un producto de AWS ni un fork de AI-DLC. Su arquitectura es propuesta y esta sujeta a investigacion/aprobación.
